# M10.14：神性光球跨战斗清理 + 全知全能平滑落地

## 1. 神性光球在下一场战斗残留

### 根因

`BelieverDivinityOrbLayer` 之前只在挂载时绑定一次神性资源：

- `_resource != null` 后 `TryBind()` 直接返回
- 战斗结束没有统一触发 `Despawn / Retire`
- 下一场战斗资源实例变化时，旧层可能仍持有旧状态和光球节点

### 修复

新增 `SyncCombatLifetime()`，在每帧更新前检查：

- 战斗结束 / 没有 `PlayerCombatState`：
  - 标记 `_combatHidden`
  - `DesiredCount = 0`
  - 所有光球 `Retire()`
  - 解绑旧 `AmountChanged` 事件
  - 清空 `_resource`
- 新战斗开始：
  - 清除 `_combatHidden`
  - 重置绑定尝试
  - `TryBind()` 重新绑定当前战斗的神性资源
  - 新资源从 0/7 开始同步，不保留上一场光球

`Bind()` / `TryBind()` / `OnAmountChanged` 都增加战斗生命周期保护。

文件：`BelieverCode/Character/BelieverDivinityOrbs.cs`

## 2. 退出全知全能时瞬移落地

### 根因

旧 `Stop()` 直接执行：

```csharp
_visualRoot.Position = _baseVisualPosition;
SetEffectVisible(false);
```

悬空高度在单帧内归零，所以看起来像瞬移。

### 修复

新增 **0.55 秒结束过渡**：

- `BeginEnding()` 记录当前悬空位置
- `UpdateEnding()` 将 visual root 从当前高度平滑插值回地面
- 同时淡出圣环、光翼、光柱、圣印和光羽
- 过渡结束后才执行最终 `Stop()` 隐藏
- 若场景提前销毁，`_ExitTree()` 仍能正常清理

文件：`BelieverCode/Character/BelieverOmniscienceDomainVfx.cs`
