| BELIEVER-LET_THERE_BE_LIGHT | 3 |

## 2. 全知全能下的 0 费

未改全知全能降费逻辑。现有：

```csharp
OmnisciencePower.TryModifyEnergyCostInCombat(...)
{
    if (card.IsMutable && card.Owner?.Creature == Owner)
    {
        modifiedCost = 0m;
        return true;
    }
}
```

因此：

- 普通状态下神迹显示/需要 **3 能量**
- 全知全能形态中任意神迹（含强化形态）动态费用为 **0**
- 退出全知全能后恢复 3 费
- 不改变抽牌、生成、消耗、稀有度或效果
