# M10.15：全知全能后光球一直为 7 的修复

## 1. 实际日志

日志中出现了明确的脱节：

```text
[BelieverOrbs] sync amount=5 desired=5 active=5 totalNodes=5
[OmniscienceDomain] activation begin, orbs=7
```

即：

- 光球层绑定/显示的是 **5 个**；
- 实际触发全知全能时神性已经是 **7 点**；
- 之后没有出现 `divinity 7 -> 0` 的同步日志；
- 光球层没有及时收到本次战斗实际资源的扣除事件，所以一直保留为 7 个。

根因不是卡牌没有扣神性，而是 **光球层持有的神性资源实例/事件与实际战斗资源脱节**。

## 2. 修复

在 `BelieverDivinityOrbs.cs` 中增加两层保护：

### 2.1 战斗生命周期清理

`SyncCombatLifetime()`：

- 战斗结束 / 无 `PlayerCombatState`：
  - 标记 `_combatHidden`
  - 所有光球 `Retire()`
  - 解绑旧资源事件
  - 清空 `_resource`
- 新战斗：
  - 重新 `TryBind()` 当前战斗资源
  - 以新战斗的 0/7 重新同步

### 2.2 每帧校验真实资源（关键）

`SyncCombatLifetime()` 每帧读取 `_player.GetResource<BelieverDivinityResource>()`：

```csharp
var current = _player.GetResource<BelieverDivinityResource>();
if (!ReferenceEquals(current, _resource))
{
    Bind(current);
    return;
}
if (!_suppressed && DesiredCount != current.Amount)
{
    Sync(current.Amount);
}
```

这样即使 `AmountChanged` 事件因为资源实例替换/时序问题没有送到光球层，下一帧也会强制对齐到真实神性值：

- 全知全能消耗 7 → 光球层收到 0 → 光球全部消失；
- 回合开始获得 1 → 只显示 1 个；
- 不会残留“上一场/上一形态的 7 个光球”。

## 3. 退出全知全能平滑落地

`BelieverOmniscienceDomainVfx.cs` 中保留并确认调用路径：

- `BeginEnding()`：记录当前悬空位置
- `UpdateEnding()`：0.55 秒从当前高度插值回地面，同时淡出圣环/光翼/光柱/光印
- 过渡完成后才 `Stop()` 隐藏

不再单帧将 `_visualRoot.Position` 直接归零。
