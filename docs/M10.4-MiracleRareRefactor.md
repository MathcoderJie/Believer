# M10.4：神迹稀有卡化、全知全能强化形态与初始卡修复

> 本阶段废弃旧的“神迹只能在全知全能中使用 / 奖励生成后再把普通稀有卡替换成神迹”规则。
> 未修改神性系统、全知全能持续时间/抽 3/清 Debuff/0 费/不扣血、遗物和普通卡效果。

## 1. 神迹改为正常稀有卡

### 规则变化

12 张神迹现在：

- 继承正常 `BelieverCard`（不再继承 `BelieverSignatureCard`）；
- 进入 `BelieverCardPool`；
- `CardRarity` 从 `Token` 改为 **`Rare`**；
- 可以像普通卡一样在普通状态打出；
- 不再由基类自动附加 `Exhaust`；
- 可以由普通稀有卡奖励抽取，不需要奖励生成后的强制替换。

### 保留

- 12 张神迹的名称、基础效果、费用和定位未改；
- 只有稀有度和“普通可玩/可收藏”机制按新规则调整；
- 自动 `Exhaust` 被移除，这是“关键词不等于消耗”的必要变化；
- 12 张基础神迹当前 `MaxUpgradeLevel = 0`，因为尚未设计强化升级；不伪造升级。

### 奖励

- 不再有“Boss 奖励全部替换成神迹”的特判。
- Boss / 普通奖励走原版稀有卡流程；Boss 的 Rare 池会从 12 张神迹中随机抽取 3 张不同候选。
- 不会同时出现全部 12 张；测试实际只出现 3 张不同神迹。
- 普通白/蓝卡奖励不受影响。
- 只保留一个“已拥有神迹去重”过滤器：如果奖励抽到已拥有神迹，替换成未拥有神迹；没有可用神迹时保留原奖励，不产生空选项。

- 描述中显示“神迹/强化神迹”关键词；

## 3. 获取与收藏

- 删除旧的“奖励生成后强制替换 + 选中后拦截不入牌组”逻辑。
- 新增 `MiracleAcquisitionPatch`：观察 `CardPileCmd.Add(..., PileType.Deck)`，当正常神迹进入主卡组时：
  - 写入 `MiracleCollectionStore.TryAdd`；
  - **允许原版入牌组流程继续**。
- 因此普通状态获得的神迹会：
  - 真正进入主卡组；
  - 同时登记到本局神迹收藏；
  - 可以被正常打出；
  - 使用/离场不会从“已获得神迹”集合中消失。
- 收藏本身仍按 run 持久化和去重，没有另建第二套神迹数据。

## 4. 全知全能强化形态

新增：

- `MiracleEnhancements`：12 张基础神迹 → 12 个强化定义映射。
- `EnhancedMiracleCard`：临时强化神迹基类。
- `EnhancedMiracles.cs`：12 个强化卡定义。

行为：

- 进入全知全能时，仍从本局收藏读取全部已获得基础神迹；
- 对每张生成对应强化卡，加入手牌；
- 不再直接发放基础神迹卡；
- 强化卡使用独立卡牌类型、独立标题/描述/关键词；
- 强化卡不会进入普通卡池、神迹目录、永久主卡组；
- 基础效果通过临时基础卡实例委托执行，不覆盖基础卡定义；
- **强化数值本轮不擅自设计**：当前强化形态暂时沿用基础效果，作为独立效果入口；具体强化数值/特效待后续设计。
- 清理逻辑只移除带 `EnhancedMiracle` 的临时强化卡，不会误删普通神迹或主卡组中的神迹。

## 5. 初始卡升级 / 变换修复

根因：三张初始卡 `StrikeBeliever` / `DefendBeliever` / `Focus` 被定义成了
`CardRarity.Common`，而原版初始卡是 `CardRarity.Basic`。这带来两个问题：

- 初始卡被普通奖励当成白卡抽取（自动化日志里确实出现过 `BELIEVER-DEFEND_BELIEVER[Common]`）；
- 只处理 `CardRarity.Basic` 的变换效果/界面会排除这些初始卡，表现为“初始卡无法变换”。

修复：

- `StrikeBeliever`、`DefendBeliever`、`Focus` 的稀有度改为 **`CardRarity.Basic`**；
- `BelieverCard` 显式声明 `MaxUpgradeLevel => 1`，避免误判不可升级；
- 不修改任何初始卡效果、费用、数值或全局变换规则。

修复后的隔离测试（真实卡牌 API）：

```text
STRIKE ... rarity=Basic maxUpgrade=1 upgradable=True transformable=True removable=True
DEFEND ... rarity=Basic maxUpgrade=1 upgradable=True transformable=True removable=True
upgraded STRIKE level=1 damage=9 description=造成 9 点伤害。
upgraded DEFEND level=1 block=8 description=获得 8 点格挡。
transform preview -> BELIEVER-ARMOR_BREAK
actual transform success=True -> BELIEVER-CONCENTRATION deck=10
```

修复后普通 Monster 奖励候选不再出现 Basic 初始卡（日志见第 6 节）。
**限制**：这是隔离 RunState 的 API 级验证，不是营火/变换界面的真实 UI 截图；UI 层仍需实机确认。
