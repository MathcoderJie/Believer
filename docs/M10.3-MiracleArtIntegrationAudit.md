## 4. 为什么不能直接裁切

1. 任务要求每个神迹使用各自的独立图片；当前文件是**总览图鉴**。
2. 图鉴格子内包含编号/中英文卡名/卡框；直接裁切会把文字和边框烘进卡图，违反
   “卡图不烘焙文字/费用/稀有度”的要求。
3. 即使只裁切画面区域，也必须先确认每个格子对应哪个**当前卡牌 ID**。
   按“大洪水≈十灾”“约柜≈拉撒复生”等主题近似绑定属于猜测，任务明确禁止。
4. 强化图鉴与普通图鉴共用同一套旧编号；如果按编号直接绑定，会把普通/强化和
   错误神迹混在一起。
