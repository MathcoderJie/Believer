## 2. 全知全能：升空、不闪攻击

### 升空

- 角色 visual root 升空约 **215px**
- 地面圣印位置补偿，角色升空时圣印仍留在地面
- 持续态保持悬停呼吸

### 不完全遮住角色

- 圣环、光翼、圣光柱、地面圣印全部位于人物背后/轮廓之外
- 光翼从左右两侧展开，内缘不穿过身体
- 圣环置于头顶上方
- 中央只保留人物本体，不再有覆盖身体的大圆盘

### 攻击不再闪光

`PlayCardBurst()` 中的全屏 `TriggerFlash` 已移除：

```csharp
public void PlayCardBurst()
{
    _cardPulse = 1f;
    _shock.Progress = 0f;
    _shock.Alpha = 0.8f;
    _shock.RadiusBoost = 0.55f;
    // no full-screen flash on attack / card play
}
```

攻击/出牌时只保留：

- 光翼脉冲
- 圣环短暂增强
- 冲击波环

不再有白屏闪。

### 保留

- 启动爆发阶段仍有必要的白金爆闪
- 受击时仍有圣盾/圣环反馈
