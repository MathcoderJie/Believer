## 4. 为什么没有开始正式绑定

当前卡牌的卡图路径由 `BelieverCard.CustomPortraitPath` / `PortraitPath` 按 **卡牌 ID** 推导，
例如：

- `BELIEVER-STRIKE_BELIEVER`
- `BELIEVER-ARMOR_BREAK`
- `BELIEVER-ENHANCED_LET_THERE_BE_LIGHT`

而资源包按 manifest 的新卡牌名提供图片。若按“名字看起来接近”强行映射：

- 大量现有卡会拿到错误图片；
- 新卡的 10 基础/15 白/15 蓝分布与当前 3 Basic/21 Common/16 Uncommon 不一致；
- 神迹基础图和强化图可能被错误交叉绑定；
- 后续真正的新卡牌定义落地后还要全部重做；
- 无法满足任务要求的“每张卡使用其 ID 对应的正确图片”。

因此当前阶段只完成资源审计，**没有复制到游戏卡图目录、没有注册新路径、没有修改卡牌代码、没有宣称游戏内显示成功**。
