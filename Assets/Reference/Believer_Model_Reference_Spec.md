**缺口（必须在正式参考图中补齐或明确生成）：**
- 单独的**背面三视图**：现有图为侧面/四分之三背面，不是严格背视。
- **分离的服装层**：现有图是完整角色，没有拆出兜帽、内袍、肩披、左右袖、下摆、圣徽、金带。
- 严格的**同等身高三视图**（正面/右侧/背面）。
- 面向游戏小尺寸的**缩小战斗小人**独立参考。

因此本阶段无法从现有图直接裁出完整的 A/B/C/D 面板；这些需要图像生成工具或美术重新绘制。当前 DSH 环境无图像生成能力，故输出完整提示词并保留缺口说明。

## 2. 目标游戏尺寸

以 Silent 现有场景为基准：

- 原生 Silent 骨架边界约 824×980 units，场景 scale 0.29，战斗可见高度约 **244–260 px**。
- 正式参考板按高分辨率制作，但设计目标按 **240–300 px 高的小人**检查轮廓。
- 头部+兜帽目标高度：**60–78 px**（约为总高的 25–30%）。
- 肩部总宽：**50–65 px**；不得过宽导致和披风混成一团。
- 胸口圣徽：**20–28 px** 直径；缩到游戏尺寸仍清楚看到外环+中央圆盘+四向短光芒。
- 金色镶边：游戏尺寸下 **2–3 px**，正式参考图中用较粗、较清晰的手绘笔触表示，避免 1px 细线。
- 长袍下摆：保持纵向，但不要过长、过尖；避免细长飘带和 1–2px 的复杂花纹。

## 4. 参考图排版（交给图像生成工具时使用）

推荐画布 3:2，至少 2400×1600：

- **Panel A（左侧约 60% 宽、上部 70% 高）**
  - 三个等高全身像：正面、右侧面、背面。
  - 同一角色、同一身高、同一头身比、同一服装结构、同一地面线。
- **Panel B（右上）**
  - 头部/兜帽：正面、右侧 3/4、背面。
  - 兜帽与肩披连接处的局部特写。
- **Panel C（右中）**
  - 服装分层：兜帽外层、内层长袍、外层披肩、左宽袖、右宽袖、前襟/下摆、背后披风、胸口圣徽、金边装饰带。
  - 每个部件单独放置、透明/深色底上可读，便于拆附件。
- **Panel D（底部横条）**
  - 面向右侧的 3/4 侧身战斗小人：双脚自然站立，一手轻抬施法，无武器，无神环/光球/特效。
  - 长袍与披风不能遮住全身轮廓。

详细生成提示词见 `Believer_Model_Reference_Prompt.md`。

## 5. 与现有 Silent 骨架的部件映射

当前 Silent 数据：141 bones / 56 slots / 1 skin / 57 attachments / 7 animations；2 IK + 11 Transform 约束。

### 5.1 头部与兜帽

- 实际骨骼：`head`（body_3 子骨，长度 100）、`head_twist`、`head_counter_twist`、`hair_base/hair1–11`、`antler_b`。
- 实际附件：
  - `head`（Mesh，96×132，138 顶点）
  - `skull`（Mesh，180×144，114 顶点）
  - `hood top`（Mesh，159×173，96 顶点）
  - `bottom hood`（Region，111×154）
  - `neck top`（Mesh，179×99，201 顶点）
  - `neck bottom`（Mesh，153×73，78 顶点）
  - `hair`、`hair top`、`eye`、`top horn`、`bottom horn`
- 设计目标映射：
  - 新兜帽外层使用独立附件，权重到 `head` + `head_twist` + `body_3`；
  - 兜帽内衬使用深色材质，覆盖头部开口；
  - 新绘制 `head` 面部阴影区域，确保黑色空洞；
  - 隐藏旧 `skull`/`hair`/`eye`/`horn`/`antler` 的显示（保留定义，不删除）；
  - 新兜帽必须覆盖死亡动画的 `death_hood`，或制作对应死亡版兜帽。

**技术限制：** `hood top`/`head`/`neck` 等 Mesh 受 DeformTimeline 引用；如果改网格拓扑，必须同步更新 deform 时间线，或把新网格作为新附件并在新 slot 上显示，不直接替换带 deform 的旧附件。

### 5.2 躯干与胸口圣徽

- 实际附件：`torso copy`（Mesh，body_1，207×200，252 顶点）、`badge`（Mesh，body_2，137×169）。
- 映射：胸口圆形圣徽画在 `torso copy` 上，或新增独立圣徽附件；外环/内环/中央圆盘/四向短光芒，保持高对比。
- 技术限制：`torso copy` 在死亡/relaxed 动画有 DeformTimeline；优先保持顶点数和拓扑，或将圣徽作为单独的、不受 deform 的附件叠加。

### 5.3 肩部披肩与披风

- 实际附件：
  - `cloak back`（Mesh，354 顶点，绑定 `capeBase`/cape_corner/center）
  - `left cape`（Mesh，40 顶点，`hip_cover`）
  - `right cape`（Mesh，447 顶点，`leg_upper_r` + leg_flap 链）
  - `top arm cloak`（Mesh，243 顶点，`arm_upper_l` + arm_flap 链）
  - `back arm cloak`（Mesh，585 顶点，`arm_upper_r` + arm_flap 链）
- 映射：
  - 多层肩披拆成 2–3 个独立附件，分别绑到 `body_3`/`shoulder_l/r`/`capeBase`；
  - 后披风保留在 `capeBase` 区域；
  - 攻击时使用的 `cape_front_attack`（624×533，342 顶点）和 `cape_back_attack`（211×279，258 顶点）需要重新绘制/缩小，避免遮住全身；不能只靠贴图透明解决。
- 技术限制：`cloak back`、`right cape`、`cape_front_attack` 等带 DeformTimeline；改网格时要保持顶点数/权重，或新附件不依赖旧 deform。

### 5.4 手臂与宽袖

- 实际附件：`top arm cloak`（左臂外层）、`back arm cloak`（右臂外层）、`top arm`/`back arm` 等内层。
- 映射：
  - 宽袖轮廓优先作为新附件绘制，权重到 `arm_upper_l/r`、`arm_lower_l/r`、`arm_flap_*`；
  - 袖口金边使用 3–4px 手绘粗线；
  - 手部采用低饱和灰白肤色，不持武器。
- 技术限制：手臂在 7 个动画中有大量 rotate/translate/scale 关键帧；新袖网格需测试 idle/attack/cast/hurt/die。

### 5.5 长袍下摆与裙摆

- 实际附件：
  - `dress`（Mesh，167×489，624 顶点，绑定 `crotch_cloth` 链）
  - `right cape` 的下摆部分（绑腿/leg_flap）
  - `bottom leg`/`top leg` 等内层
- 映射：
  - 前襟/裙摆作为独立层，权重到 `crotch_cloth1–6`；
  - 保留纵向尖角与层叠，但缩短到游戏可读长度；
  - 腿部尽量用深色内袍阴影覆盖，避免白色碎块。
- 技术限制：`dress` 顶点数较多且有动画；修改拓扑需重新处理权重/Deform 时间线；建议新附件独立绘制。

## 6. 视觉验收清单

参考板/后续美术必须满足：

- [ ] 头部：尖顶兜帽明显区别于 Silent；面部完全隐藏；无眼睛/鼻子/嘴/骷髅/鹿角/头发。
- [ ] 兜帽：有立体布料层次、深色内部、象牙白外层、克制古金边。
- [ ] 肩部：多层披肩，向外延展但不过宽，缩小时轮廓可辨。
- [ ] 躯干：象牙白纵向长袍，灰褐阴影，布料厚度清楚。
- [ ] 胸口：清晰圆形金色圣徽，缩到 20–28px 仍可读。
- [ ] 袖子：宽袖+金袖口，手部自然、无武器。
- [ ] 下摆：多层、尖角、褶皱、垂坠；不遮住全身。
- [ ] 背视：兜帽尖顶/披肩/披风/长袍层次完整。
- [ ] 侧面小人：面向右侧，双脚自然，手势引导，无神环/光球/特效。
- [ ] 全部视图设计一致；无多余肢体/手指；无现代 3D/塑料质感。
